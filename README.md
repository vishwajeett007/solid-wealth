# LuxeFinance

Production-ready App Router landing page for LuxeFinance, converted from a
single HTML file into a modular Next.js project.

## Project Structure

```text
src/
  app/
    layout.tsx
    page.tsx
  components/
    layout/
    sections/
    ui/
  lib/
  styles/
```

## Getting Started

```bash
npm run dev
```

Open http://localhost:3000 to view the app.

## Quality Checks

```bash
npm run lint
npm run build
```
